## How course notes work

- **Course folder** — the syllabus, schedule, progress and course-specific
  observations.
- **`03-Concepts/`** — anything true independently of the course. A note about
  Raft belongs there and is *linked* from the course, not duplicated into it.
- **Labs** — assignment write-ups go in [04-Labs](../04-Labs/README.md) when
  they answer a general question; course-specific ones stay in the course
  folder.

!!! warning "Never commit course solution code here"
    Both courses ask that solutions are not published, and this repository is
    intended to be public. Keep assignment code in a separate private
    repository.
