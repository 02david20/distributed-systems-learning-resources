Complements MIT 6.5840 rather than duplicating it: 6.5840 goes deep on
consensus and implementation; this specialization is broader on cloud systems,
gossip protocols, key-value stores and stream processing.

## Objectives

- [ ] Explain gossip/epidemic protocols and their convergence properties
- [ ] Explain the Dynamo-style key-value store design end to end
